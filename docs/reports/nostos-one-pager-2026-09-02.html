Nostos Keeps an app's data up to date on every phone and laptop — even when the internet drops out.

Test report for non-technical readers
2 September 2026

What Nostos is

One source of truth, everywhere

Every change in the central database is pushed to all connected devices, and every device's changes come back. Everyone sees the same data.

Works offline

Each device keeps its own copy. Lose signal on a train, keep working; it catches up when you're back online.

Free and open

Apache-2.0 licence — anyone can use it, including commercially, at no cost. The main competitor (PowerSync) has a restricted licence.

What we tested, in plain terms

Think of a post office

Nostos's server is the post office. Each app on a phone is a mailbox. We opened thousands of mailboxes at once, dropped hundreds of millions of letters into the post office, then counted how fast they were delivered and how many went missing.

The setup

  • One computer (a 10-core Mac) plays both the post office and every mailbox.
  • From 1,000 up to 100,000 mailboxes; on macOS and inside a Linux container.
  • Runs repeated; we keep the middle result and always report what was lost.

100,000 mailboxes: one run delivered 99.9%, another only 20%. Every bad run happened while the computer was busy with other work, so we don't trust either number yet. It needs a re-run on a quiet machine.

A real bug this testing found — and fixed

For every letter, the server used to start one separate chore per mailbox — 10,000 chores per letter at 10,000 mailboxes. We changed it to one pass over all mailboxes.

Honest caveats

  • The letters came from a simulator, not a live database. A separate real-database test delivers about 35,000 updates per second end-to-end — a different measurement, not comparable to the charts.
  • Everything ran on one machine. A real deployment spreads the load across several.
  • Numbers at 30,000 mailboxes and above are lower bounds: the test rig couldn't open every mailbox in time, and the runs stopped at a fixed time limit.
  • PowerSync publishes no comparable figure for this stage of the pipeline, so there is no apples-to-apples comparison yet. A head-to-head test is designed but on hold.
