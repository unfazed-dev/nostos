Nostos Keeps an app's data up to date on every phone and laptop — even when the internet drops out.

Test report for non-technical readers
2 September 2026

What Nostos is

One source of truth, everywhere

Every change made in the central database is pushed out to all connected devices, and every device's changes come back. Everyone sees the same data.

Works offline

Each device keeps its own copy. Lose signal on a train, keep working; it catches up when you're back online.

Free and open

Apache-2.0 licence — anyone can use it, including commercially, at no cost. The main competitor (PowerSync) has a restricted licence.

What we tested, in plain terms

Think of a post office

Nostos's server is the post office. Each app on a phone is a mailbox. We opened thousands of mailboxes at once, dropped tens of millions of letters into the post office, then counted two things: how fast they were delivered and how many went missing.

The setup

  • One computer (a 10-core Mac) plays both post office and all the mailboxes.
  • Runs from 1,000 up to 100,000 mailboxes, on macOS and inside a Linux container.
  • Each run repeated; we keep the middle result and report anything lost.

A real bug this testing found — and fixed

For every letter, the server used to start one separate chore per mailbox. At 10,000 mailboxes that's 10,000 chores per letter, and the post office ground to a halt (only 25,600 deliveries per second). We changed it to one pass over all mailboxes. The same test then did 424,000 per second — and the 1,000-device number rose from 833,000 to 2.6 million.

Honest caveats

  • The "letters" came from a simulator, not a live database. A separate real-database test delivers ~35,000 updates per second end-to-end — a different measurement.
  • Everything ran on one machine; a real deployment spreads the load.
  • PowerSync publishes no comparable figure for this stage, so there is no apples-to-apples comparison yet. A head-to-head test is designed but on hold.
